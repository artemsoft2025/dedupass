        Утилита для работы со словарями паролей
                    (Linux)

   (c) 2026 AKSoft

   Удаление дубликатов и объединение текстовых файлов
   с паролями. Работает с файлами любого размера
   (проверено на 100+ ГБ).


================================================================
   ДОСТУПНЫЕ ВЕРСИИ
================================================================

   dedupass        - консольная версия (CLI)
   dedupass_gui    - графическая версия (GUI)

   Обе версии полностью автономны:
     - не требуют Python (после сборки)
     - не требуют интернета
     - не требуют прав root
     - не оставляют следов в системе


================================================================
   БЫСТРЫЙ СТАРТ
================================================================

   1. Дайте файлам право на выполнение:

        chmod +x dedupass dedupass_gui

   2. Запустите нужную версию:

        ./dedupass          консольная версия
        ./dedupass_gui      графическая версия

   3. Или запустите двойным кликом из файлового менеджера
      (для GUI версии — по умолчанию).


================================================================
   УСТАНОВКА В СИСТЕМУ (опционально)
================================================================

   Если хотите запускать dedupass из любой папки
   и видеть GUI в меню приложений:

   ----- Способ 1: автоматический -----

   Если у вас есть исходники — запустите:

        chmod +x install/install.sh
        ./install/install.sh

   Скрипт установит:
     - бинарники в ~/.local/bin/
     - иконку в ~/.local/share/icons/
     - .desktop-файл для меню приложений

   ----- Способ 2: вручную -----

   Скопируйте бинарники:

        mkdir -p ~/.local/bin
        cp dedupass ~/.local/bin/
        cp dedupass_gui ~/.local/bin/
        chmod +x ~/.local/bin/dedupass
        chmod +x ~/.local/bin/dedupass_gui

   Убедитесь, что ~/.local/bin в PATH:

        echo $PATH | grep -q "$HOME/.local/bin" || \
          echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

        source ~/.bashrc

   Готово! Теперь можно вызывать:

        dedupass --help
        dedupass_gui


   ----- Удаление -----

        rm ~/.local/bin/dedupass
        rm ~/.local/bin/dedupass_gui
        rm ~/.local/share/applications/dedupass_gui.desktop

   Или через скрипт:

        chmod +x install/uninstall.sh
        ./install/uninstall.sh


================================================================
   ГРАФИЧЕСКАЯ ВЕРСИЯ (dedupass_gui)
================================================================

   Запуск:

        ./dedupass_gui

   Интерфейс содержит две вкладки:

     [🗑 Удалить дубликаты]
        - Входной файл (кнопка "Обзор...")
        - Выходной файл (опционально;
          если пусто — перезаписать входной)
        - Кнопка "▶ Удалить дубликаты"

     [🔗 Объединить файлы]
        - Список файлов для объединения
        - Кнопки: "+ Добавить файлы", "+ По маске",
          "✕ Удалить", "⌫ Очистить"
        - Выходной файл (кнопка "Обзор...")
        - Кнопка "▶ Объединить и очистить"

   Элементы управления:

     Прогресс-бар     - показывает процент выполнения
     Кнопка "Отмена"  - безопасно прерывает операцию
     Журнал           - лог всех операций с цветовой
                        подсветкой (зелёный — успех,
                        красный — ошибка, жёлтый —
                        предупреждение)

   Особенности GUI:

     - Автоопределение кодировки
     - Прогресс-бар с реальным процентом
     - Отмена операции в один клик
     - Поддержка масок файлов ("*.txt", "data/*.txt")
     - Безопасная работа с большими файлами
     - Автоматическое раскрытие ~ в путях

   Требования:

     Для работы GUI версии в системе должен быть
     установлен Tkinter:

       Ubuntu/Debian:  sudo apt install python3-tk
       Fedora/RHEL:    sudo dnf install python3-tkinter
       Arch/Manjaro:   sudo pacman -S tk
       openSUSE:       sudo zypper install python3-tk

     В собранном PyInstaller-бинарнике Tkinter уже
     встроен, поэтому для запуска готового бинарника
     установка Tkinter НЕ требуется.


================================================================
   КОНСОЛЬНАЯ ВЕРСИЯ (dedupass)
================================================================

   Запуск без параметров открывает интерактивное меню:

     1. Удалить дубликаты в файле
     2. Объединить несколько файлов
     3. Использовать файл со списком
     4. Показать справку
     5. Выйти

   Для опытных пользователей — команды с параметрами.


   ---------------------------------------------------------
   1. УДАЛЕНИЕ ДУБЛИКАТОВ В ОДНОМ ФАЙЛЕ
   ---------------------------------------------------------

     dedupass --remove-duplicates файл.txt
     dedupass -rd файл.txt

   Файл обрабатывается "на месте" — перезаписывается
   без дубликатов. Оригинал не сохраняется.

   Пример:
     dedupass -rd ~/rockyou.txt


   ---------------------------------------------------------
   2. СОЗДАНИЕ ОЧИЩЕННОЙ КОПИИ
   ---------------------------------------------------------

     dedupass --output результат.txt исходник.txt
     dedupass -o чистый.txt грязный.txt

   Оригинал не трогается, создаётся новый файл.

   Пример:
     dedupass -o clean.txt dirty.txt


   ---------------------------------------------------------
   3. ОБЪЕДИНЕНИЕ НЕСКОЛЬКИХ ФАЙЛОВ
   ---------------------------------------------------------

     dedupass --output результат.txt файл1.txt файл2.txt
     dedupass -o общий.txt "папка/*.txt"

   ⚠️  ВАЖНО (Linux): маски файлов нужно
       ЗАКЛЮЧАТЬ В КАВЫЧКИ. Подробнее — в разделе
       "МАСКИ ФАЙЛОВ".

   Примеры:
     dedupass -o combined.txt file1.txt file2.txt
     dedupass -o all.txt "passwords/*.txt"


   ---------------------------------------------------------
   4. ИСПОЛЬЗОВАНИЕ ФАЙЛА-СПИСКА
   ---------------------------------------------------------

     dedupass --list список.txt --output результат.txt
     dedupass -l файлы.list -o итог.txt

   Файл-список — это текстовый файл со списком
   файлов для обработки. Подробнее — в разделе
   "ФАЙЛЫ-СПИСКИ" ниже.


   ---------------------------------------------------------
   5. КОМБИНИРОВАНИЕ РАЗНЫХ ИСТОЧНИКОВ
   ---------------------------------------------------------

     dedupass --list основной.list --output mega.txt "доп/*.txt"

   Можно одновременно использовать:
     - файл-список (-l)
     - маски файлов
     - конкретные файлы


   ---------------------------------------------------------
   6. ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ
   ---------------------------------------------------------

     dedupass --help       показать справку
     dedupass -h           то же самое
     dedupass --version    показать версию
     dedupass -v           то же самое
     dedupass              интерактивное меню


================================================================
   ФАЙЛЫ-СПИСКИ (.list, .txt)
================================================================

   Файл-список — это обычный текстовый файл,
   содержащий пути к файлам и маски.

   Правила:

     - Каждая строка = один путь или маска
     - Строки, начинающиеся с #, игнорируются
     - Пустые строки игнорируются
     - Вложенные списки через @
     - Абсолютные пути поддерживаются
     - ~ раскрывается в домашнюю директорию

   Пример файла my.list:

     # Список словарей для обработки
     ~/rockyou.txt
     ~/passwords/darkc0de.txt
     folder/*.txt
     data/2024_*.txt
     @additional.list

     # Абсолютные пути тоже работают
     /home/user/dictionaries/special.txt


   Вложенный список additional.list:

     # Дополнительные источники
     extra/dict1.txt
     extra/dict2.txt


   Использование:

     dedupass --list my.list --output result.txt
     dedupass -l my.list -o result.txt


================================================================
   МАСКИ ФАЙЛОВ
================================================================

   Маски — это шаблоны имён файлов. Поддерживаются:

     *         - любое количество любых символов
     ?         - один любой символ
     [abc]     - один из символов a, b или c
     [a-z]     - любой символ из диапазона

   Примеры:

     "*.txt"             все .txt файлы в текущей папке
     "data/*.txt"        все .txt файлы в папке data
     "*/*.txt"           все .txt в подпапках (1 уровень)
     "*/*/*.txt"         все .txt в подпапках (2 уровня)
     "2024_*.txt"        файлы, начинающиеся с "2024_"
     "password?.txt"     password1.txt, password2.txt и т.д.


   ⚠️  ВАЖНОЕ ОТЛИЧИЕ ОТ WINDOWS:

   В Linux маски раскрывает оболочка (bash / zsh)
   ДО того, как команда попадёт в dedupass.

   Это значит:

     ПРАВИЛЬНО:   dedupass -o all.txt "*.txt"
     НЕПРАВИЛЬНО: dedupass -o all.txt *.txt

   Во втором случае оболочка сама подставит список
   файлов. Если файлов много — командная строка
   может переполниться (ошибка "argument list too long").

   Всегда используйте кавычки для масок.


================================================================
   ОСОБЕННОСТИ
================================================================

   - Автоопределение кодировки
     UTF-8, CP1251, CP866, KOI8-R, Latin-1,
     ISO-8859-1 — определяется автоматически
     по 3 фрагментам файла.

   - Сохранение порядка строк
     Строки в итоговом файле идут в том порядке,
     в котором они впервые встретились.

   - Обработка очень больших файлов
     Для файлов > 50 МБ (дедупликация) или
     > 500 МБ (объединение) автоматически
     включается потоковый режим с чанками.
     Работает даже с файлами 100+ ГБ.

   - Оптимизация размера
     После обработки файл автоматически
     оптимизируется: удаляются пустые строки,
     лишние пробелы, BOM-маркер.

   - Показ примеров удалённых дубликатов
     После операции показываются первые 5
     удалённых дубликатов (до 60 символов).

   - Безопасное прерывание
     CLI: Ctrl+C → диалог "Немедленно завершить? (y/n)".
     GUI: кнопка "⏹ Отмена".
     Операция прерывается безопасно, исходные
     файлы не портятся.

   - Проверка доступа
     Программа проверяет права на чтение входных
     файлов и права на запись в выходной файл
     ДО начала обработки.

   - Раскрытие ~ в путях
     ~/rockyou.txt → /home/user/rockyou.txt
     Работает во всех аргументах и в файлах-списках.


================================================================
   ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
================================================================

   ► Очистить rockyou.txt от дубликатов:

       ./dedupass -rd ~/rockyou.txt


   ► Создать очищенную копию, не трогая оригинал:

       ./dedupass -o ~/rockyou_clean.txt ~/rockyou.txt


   ► Объединить два словаря:

       ./dedupass -o combined.txt rockyou.txt darkc0de.txt


   ► Объединить все .txt файлы в папке:

       ./dedupass -o all.txt "passwords/*.txt"


   ► Объединить все .txt рекурсивно:

       ./dedupass -o all.txt "*.txt" "*/*.txt" "*/*/*.txt"


   ► Использовать файл-список:

       ./dedupass -l my.list -o result.txt


   ► Комбинировать список и маску:

       ./dedupass -l main.list -o mega.txt "extra/*.txt"


   ► Запустить GUI и удалить дубликаты:

       ./dedupass_gui
       # выбрать файл, нажать "Удалить дубликаты"


================================================================
   ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ (FAQ)
================================================================


   ВОПРОС: ./dedupass: Permission denied
   ОТВЕТ:  Дайте файлу право на выполнение:
             chmod +x dedupass
             chmod +x dedupass_gui


   ВОПРОС: ./dedupass_gui: error while loading shared libraries:
           libtk8.6.so: cannot open shared object file
   ОТВЕТ:  Бинарник собран с динамической линковкой к Tk.
           Установите Tk:
             sudo apt install tk
           Или пересоберите GUI версию с флагом --windowed
           (PyInstaller встраивает Tk в бинарник).


   ВОПРОС: ./dedupass_gui: error while loading shared libraries:
           libc.so.6: version `GLIBC_2.34' not found
   ОТВЕТ:  Бинарник собран на более новой системе, чем у вас.
           Решения:
             - Скачайте бинарник для более старой системы
             - Пересоберите сами на своей системе
             - Используйте .py-версию при наличии Python


   ВОПРОС: Программа удалила не все дубликаты.
   ОТВЕТ:  Дубликаты определяются по точному совпадению
           после trim (удаления пробелов в начале и конце).
           "password" и "password " считаются одинаковыми.
           "password" и "Password" — разными
           (регистр учитывается).


   ВОПРОС: Файл после обработки стал больше, а не меньше.
   ОТВЕТ:  Возможно, у вас были строки без завершающего
           перевода строки, и dedupass добавил его. Либо
           файл был в однобайтовой кодировке (CP1251),
           а сохранён в UTF-8. Это нормально.


   ВОПРОС: Маски не работают.
   ОТВЕТ:  В Linux их раскрывает оболочка. Заключайте
           маски в кавычки:
             ПРАВИЛЬНО:   dedupass -o all.txt "*.txt"
             НЕПРАВИЛЬНО: dedupass -o all.txt *.txt


   ВОПРОС: Как обрабатывать файлы с ~ в путях?
   ОТВЕТ:  ~ раскрывается автоматически. Можно писать
           ~/rockyou.txt или /home/user/rockyou.txt.


   ВОПРОС: Программа зависла на большом файле.
   ОТВЕТ:  Нажмите Ctrl+C для безопасной остановки.
           В GUI — кнопка "Отмена". Прогресс виден
           в GUI (процент) или в CLI (для больших
           файлов периодически печатается прогресс).


   ВОПРОС: Антивирус / EDR ругается на бинарник.
   ОТВЕТ:  Ложное срабатывание из-за упаковки
           PyInstaller. Файл безопасен. Если смущает —
           соберите сами из исходников (инструкция
           в разделе "СБОРКА ИЗ ИСХОДНИКОВ") или
           добавьте в исключения.


   ВОПРОС: Поддерживается ли Unicode?
   ОТВЕТ:  Да. Файлы в UTF-8 обрабатываются корректно,
           включая эмодзи, иероглифы, кириллицу.
           Кодировка определяется автоматически.


   ВОПРОС: Работает ли на сервере без графики?
   ОТВЕТ:  CLI-версия — да, работает без X11/Wayland.
           GUI-версия требует графического окружения.


   ВОПРОС: Как добавить GUI в меню приложений?
   ОТВЕТ:  Запустите install/install.sh — он установит
           .desktop-файл в ~/.local/share/applications/.
           После этого dedupass GUI появится в меню
           приложений вашего окружения (GNOME, KDE,
           XFCE и др.).
