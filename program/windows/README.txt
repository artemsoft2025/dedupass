   Удаление дубликатов и объединение текстовых файлов
   с паролями. Работает с файлами любого размера
   (проверено на 100+ ГБ).


================================================================
   ДОСТУПНЫЕ ВЕРСИИ
================================================================

   dedupass.exe       - консольная версия (CLI)
   dedupass_gui.exe   - графическая версия (GUI)

   Обе версии полностью автономны:
     - не требуют установки
     - не требуют Python
     - не требуют интернета
     - не оставляют следов в реестре

   Выбирайте ту, что удобнее. Функциональность
   у обеих одинаковая.


================================================================
   УСТАНОВКА
================================================================

   Установка не требуется. Просто запустите .exe.

   Опционально: чтобы запускать dedupass из любой папки,
   добавьте папку с dedupass.exe в переменную окружения PATH.

   Windows:
     1. Правый клик "Этот компьютер" -> Свойства
     2. Дополнительные параметры системы
     3. Переменные среды
     4. В разделе "Переменные пользователя" найдите Path
     5. Добавьте путь к папке с dedupass.exe
     6. Перезапустите командную строку


================================================================
   ГРАФИЧЕСКАЯ ВЕРСИЯ (dedupass_gui.exe)
================================================================

   Запуск: двойной клик по dedupass_gui.exe

   Интерфейс содержит две вкладки:

     [🗑 Удалить дубликаты]
        - Входной файл (кнопка "Обзор...")
        - Выходной файл (опционально; если пусто —
          перезаписать входной)
        - Кнопка "▶ Удалить дубликаты"

     [🔗 Объединить файлы]
        - Список файлов для объединения
        - Кнопки: "+ Добавить файлы", "+ По маске",
          "✕ Удалить", "⌫ Очистить"
        - Выходной файл (кнопка "Обзор...")
        - Кнопка "▶ Объединить и очистить"

   Элементы управления:

     Прогресс-бар     - показывает процент выполнения
     Кнопка "Отмена"  - безопасно прерывает операцию
     Журнал           - лог всех операций с цветовой
                        подсветкой (зелёный — успех,
                        красный — ошибка, жёлтый —
                        предупреждение)

   Особенности GUI:
     - Автоопределение кодировки
     - Прогресс-бар с реальным процентом
     - Отмена операции в один клик
     - Поддержка масок файлов (*.txt, data/*.txt)
     - Безопасная работа с большими файлами


================================================================
   КОНСОЛЬНАЯ ВЕРСИЯ (dedupass.exe)
================================================================

   Запуск без параметров открывает интерактивное меню:

     1. Удалить дубликаты в файле
     2. Объединить несколько файлов
     3. Использовать файл со списком
     4. Показать справку
     5. Выйти

   Для опытных пользователей — команды с параметрами:


   ---------------------------------------------------------
   1. УДАЛЕНИЕ ДУБЛИКАТОВ В ОДНОМ ФАЙЛЕ
   ---------------------------------------------------------

     dedupass.exe --remove-duplicates файл.txt
     dedupass.exe -rd файл.txt

   Файл обрабатывается "на месте" — перезаписывается
   без дубликатов. Оригинал не сохраняется.

   Пример:
     dedupass.exe -rd rockyou.txt


   ---------------------------------------------------------
   2. СОЗДАНИЕ ОЧИЩЕННОЙ КОПИИ
   ---------------------------------------------------------

     dedupass.exe --output результат.txt исходник.txt
     dedupass.exe -o чистый.txt грязный.txt

   Оригинал не трогается, создаётся новый файл.

   Пример:
     dedupass.exe -o clean.txt dirty.txt


   ---------------------------------------------------------
   3. ОБЪЕДИНЕНИЕ НЕСКОЛЬКИХ ФАЙЛОВ
   ---------------------------------------------------------

     dedupass.exe --output результат.txt файл1.txt файл2.txt файл3.txt
     dedupass.exe -o общий.txt папка/*.txt

   Все файлы читаются, дубликаты удаляются,
   результат сохраняется в выходной файл.
   Порядок строк сохраняется (первое появление строки
   побеждает).

   Примеры:
     dedupass.exe -o combined.txt file1.txt file2.txt
     dedupass.exe -o all.txt passwords/*.txt


   ---------------------------------------------------------
   4. ИСПОЛЬЗОВАНИЕ ФАЙЛА-СПИСКА
   ---------------------------------------------------------

     dedupass.exe --list список.txt --output результат.txt
     dedupass.exe -l файлы.list -o итог.txt

   Файл-список — это текстовый файл со списком
   файлов для обработки. Подробнее в разделе
   "ФАЙЛЫ-СПИСКИ" ниже.


   ---------------------------------------------------------
   5. КОМБИНИРОВАНИЕ РАЗНЫХ ИСТОЧНИКОВ
   ---------------------------------------------------------

     dedupass.exe --list основной.list --output mega.txt доп/*.txt

   Можно одновременно использовать:
     - файл-список (-l)
     - маски файлов
     - конкретные файлы


   ---------------------------------------------------------
   6. ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ
   ---------------------------------------------------------

     dedupass.exe --help       показать справку
     dedupass.exe -h           то же самое
     dedupass.exe --version    показать версию
     dedupass.exe -v           то же самое
     dedupass.exe              интерактивное меню


================================================================
   ФАЙЛЫ-СПИСКИ (.list, .txt)
================================================================

   Файл-список — это обычный текстовый файл,
   содержащий пути к файлам и маски.

   Правила:
     - Каждая строка = один путь или маска
     - Строки, начинающиеся с #, игнорируются
     - Пустые строки игнорируются
     - Поддерживаются вложенные списки через @
     - Поддерживаются абсолютные пути

   Пример файла my.list:

     # Список словарей для обработки
     rockyou.txt
     passwords/darkc0de.txt
     folder/*.txt
     data/2024_*.txt
     @additional.list

     # Абсолютные пути тоже работают
     C:\Dictionaries\special.txt


   Вложенный список:

     Файл additional.list:

       # Дополнительные источники
       extra/dict1.txt
       extra/dict2.txt


   Использование:

     dedupass.exe --list my.list --output result.txt
     dedupass.exe -l my.list -o result.txt


================================================================
   МАСКИ ФАЙЛОВ
================================================================

   Маски — это шаблоны имён файлов. Поддерживаются:

     *         - любое количество любых символов
     ?         - один любой символ
     [abc]     - один из символов a, b или c
     [a-z]     - любой символ из диапазона

   Примеры:

     *.txt              все .txt файлы в текущей папке
     data/*.txt         все .txt файлы в папке data
     */*.txt            все .txt в подпапках (1 уровень)
     */*/*.txt          все .txt в подпапках (2 уровня)
     2024_*.txt         файлы, начинающиеся с "2024_"
     password?.txt      password1.txt, password2.txt и т.д.
     data/[abc]*.txt    файлы в data, начинающиеся с a, b или c

   Важно: на Windows маски раскрываются оболочкой cmd.exe
   ДО запуска dedupass. Если нужно, чтобы маску
   раскрыл dedupass, заключите её в кавычки:

     dedupass.exe -o result.txt "data/*.txt"


================================================================
   ОСОБЕННОСТИ
================================================================

   - Автоопределение кодировки
     UTF-8, CP1251, CP866, Latin-1, ISO-8859-1,
     Windows-1252 — определяется автоматически
     по 3 фрагментам файла (начало, середина, конец).

   - Сохранение порядка строк
     Строки в итоговом файле идут в том порядке,
     в котором они впервые встретились.

   - Обработка очень больших файлов
     Для файлов > 50 МБ (дедупликация) или
     > 500 МБ (объединение) автоматически
     включается потоковый режим с чанками.
     Работает даже с файлами 100+ ГБ.

   - Оптимизация размера
     После обработки файл автоматически
     оптимизируется: удаляются пустые строки,
     лишние пробелы, BOM-маркер.

   - Показ примеров удалённых дубликатов
     После операции показываются первые 5
     удалённых дубликатов (до 60 символов).

   - Безопасное прерывание
     В CLI: Ctrl+C -> диалог "Немедленно завершить? (y/n)".
     В GUI: кнопка "⏹ Отмена".
     Операция прерывается безопасно, исходные файлы
     не портятся.

   - Проверка доступа
     Программа проверяет права на чтение входных
     файлов и права на запись в выходной файл
     ДО начала обработки.


================================================================
   ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
================================================================

   ► Очистить rockyou.txt от дубликатов:

       dedupass.exe -rd rockyou.txt


   ► Создать очищенную копию, не трогая оригинал:

       dedupass.exe -o rockyou_clean.txt rockyou.txt


   ► Объединить два словаря:

       dedupass.exe -o combined.txt rockyou.txt darkc0de.txt


   ► Объединить все .txt файлы в папке:

       dedupass.exe -o all.txt "passwords/*.txt"


   ► Объединить все .txt рекурсивно:

       dedupass.exe -o all.txt "*.txt" "*/*.txt" "*/*/*.txt"


   ► Использовать файл-список:

       dedupass.exe -l my.list -o result.txt


   ► Комбинировать список и маску:

       dedupass.exe -l main.list -o mega.txt "extra/*.txt"


================================================================
   ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ (FAQ)
================================================================


   ВОПРОС: Программа удалила не все дубликаты.
   ОТВЕТ:  Дубликаты определяются по точному совпадению
           после trim (удаления пробелов в начале и конце).
           Строки "password" и "password " считаются
           одинаковыми. А "password" и "Password" — разными
           (регистр учитывается).


   ВОПРОС: Файл после обработки стал больше, а не меньше.
   ОТВЕТ:  Возможно, у вас были строки без завершающего
           перевода строки, и dedupass добавил его. Либо
           файл был в однобайтовой кодировке (CP1251),
           а сохранён в UTF-8 — для не-ASCII символов
           UTF-8 занимает больше байт. Это нормально.


   ВОПРОС: Программа зависла на большом файле.
   ОТВЕТ:  Проверьте прогресс в GUI (процент выполнения)
           или в CLI (при больших файлах dedupass
           периодически печатает прогресс). Нажмите Ctrl+C
           для безопасной остановки.


   ВОПРОС: Антивирус ругается на dedupass.exe.
   ОТВЕТ:  Это ложное срабатывание из-за упаковки
           PyInstaller --onefile. Файл безопасен.
           Если смущает — соберите сами из исходников
           (инструкция ниже) или добавьте в исключения.


   ВОПРОС: Как обрабатывать файлы с паролями,
           содержащими пробелы?
   ОТВЕТ:  Пробелы в начале и конце строки удаляются.
           Если пароль "  test  ", он будет сохранён
           как "test". Если пароль содержит пробелы
           внутри — "my pass" — они сохранятся.


   ВОПРОС: Поддерживается ли Unicode?
   ОТВЕТ:  Да. Файлы в UTF-8 обрабатываются корректно,
           включая эмодзи, иероглифы, кириллицу.
           Кодировка определяется автоматически.


================================================================
   СБОРКА ИЗ ИСХОДНИКОВ (для разработчиков)
================================================================

   Требования:
     - Python 3.7+
     - PyInstaller

   Шаги:

   1. Установите PyInstaller:

        pip install pyinstaller


   2. (Опционально) Положите icon.ico рядом
      со скриптами. Если файла нет — сборка
      пройдёт без иконки.


   3. Соберите нужную версию:

        build_cli.bat    только консольная версия
        build_gui.bat    только GUI версия
        build_all.bat    обе версии


   4. Результат появится в папке dist\:

        dist\dedupass.exe        консольная версия
        dist\dedupass_gui.exe    графическая версия


   Структура исходников:

     dedupass.py           ядро + CLI
     dedupass_gui.py       ядро + GUI (автономный)
     build_cli.bat         сборка консольной версии
     build_gui.bat         сборка GUI версии
     build_all.bat         сборка обеих версий
     version_info.txt      метаданные для EXE (опционально)
     icon.ico              иконка (опционально)
     README.txt            этот файл


================================================================
   ТЕХНИЧЕСКИЕ ДЕТАЛИ
================================================================

   Размер одного .exe:      ~10-15 МБ
   Время первого запуска:   1-3 секунды (распаковка
                            PyInstaller во временную папку)
   Время последующих:       быстрее
   Работает на:             Windows 7 / 8 / 10 / 11
                            (32-bit и 64-bit)

   Не требует:
     - прав администратора
     - установки Python
     - интернет-соединения
     - регистрации

   Оставляет следы только в:
     - %TEMP%\_MEIxxxxx (временная папка PyInstaller;
       удаляется автоматически при выходе)
     - временных файлах в папке с обрабатываемым
       файлом (только во время работы, потом
       удаляются автоматически)
